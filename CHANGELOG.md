# Changelog

## [2.1.0] - YSCMT OS Foundation Release

### Added

- YSCMT OS 2.1 release identity
- Foundation codename
- XFCE desktop environment
- Firefox ESR
- Python development environment
- Node.js and npm
- C/C++ development toolchain
- Git and common command-line utilities
- NetworkManager
- OpenSSH client
- Nmap and tcpdump
- DNS and network diagnostic utilities
- YSCMT OS user creation
- YSCMT hostname configuration
- YSCMT release metadata

### Build

- Debian GNU/Linux base
- amd64 architecture
- Debian Live build configuration
- Build configuration tracked under `config/`

### Release verification

The YSCMT OS 2.1 ISO was verified as bootable and its SHA-256 checksum was validated before release.
