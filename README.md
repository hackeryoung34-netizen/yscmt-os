# YSCMT OS

**YSCMT OS 2.1 — Foundation**

YSCMT OS is a Debian-based Linux distribution developed by YSCMT Community for education, software development, cybersecurity, technology, and open-source learning.

## YSCMT OS 2.1

- **Version:** 2.1
- **Codename:** Foundation
- **Architecture:** amd64
- **Desktop:** XFCE
- **Base:** Debian GNU/Linux
- **Purpose:** Education, Software Development, Cybersecurity, Technology, Open Source

## Features

- XFCE desktop environment
- Firefox ESR
- Python 3
- Node.js and npm
- GCC / G++ / Make / CMake
- Git
- NetworkManager
- OpenSSH client
- Nmap
- tcpdump
- DNS utilities
- Vim and Nano
- tmux
- jq
- Common development utilities

## Building YSCMT OS

YSCMT OS is built using Debian Live live-build tooling.

The build configuration is contained in the `config/` directory.

Generated build artifacts such as ISO images, chroot data, caches, and build logs are intentionally excluded from Git.

## Release

The official YSCMT OS releases contain the ISO image and corresponding SHA-256 verification files.

Always verify the downloaded ISO against the published SHA-256 checksum before using it.
